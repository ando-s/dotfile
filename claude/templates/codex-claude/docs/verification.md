# 検証の進め方

変更した振る舞いを最短の方法で確認する。細かい確認は自動テストに任せ、人にしかできない確認は本人の実機確認にまとめる。

| 確認 | いつ・どうやって |
|---|---|
| 自動テスト | 変更のたび。同じ画面確認が2回必要になったら Playwright などのスクリプトにする |
| 実AIへのリクエスト | 生成・プロンプト・認証を変えたときだけ。区切りでまとめて行う |
| 公開版の確認 | デプロイ後に1回。ヘルスチェックと主要な API を HTTP で呼ぶ |
| 音・マイク・見た目 | 本人の実機確認でまとめて確かめる |
| computer 機能やブラウザの手動操作 | 原則として使わない。他で確かめられず先に進めない場合だけ使い、理由を [worklog.md](worklog.md) に書く |
