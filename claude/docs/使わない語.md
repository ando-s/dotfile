# 使わない語

ユーザーに「わかりにくい」「違和感がある」と言われた語と、代わりの書き方。
Claude はユーザーへの返答や、人に渡す文章を書くときにこの一覧を確かめ、ここにある語を使わない。
新しく指摘された語は、ここに1行足す（weekly-rules でも足す案を出す）。

## Claude 側の名前（ユーザーの画面での呼び方と違うもの）

| 使わない語 | 代わりの書き方 |
|---|---|
| Other（質問の画面の自由入力） | 選択肢の下の、自由に書ける欄 |
| AskUserQuestion | 質問の画面、選択肢で聞く |
| サブエージェント、Agent | 別の作業として任せる、並行で調べる |
| frontmatter、skillOverrides などの設定のキー | 何をする設定かを書く（例: スキルを止める設定）。キーが要るときはコードとして別の行に書く |

## 硬い語・馴染みのない語

| 使わない語 | 代わりの書き方 |
|---|---|
| 正典、正典化 | 正本、元にするもの |
| あらまし | 概要、全体像 |
| 不可逆 | 元に戻せない |
| 事実（見出しや区分の名前として） | 何についての話かを書く |
| 距離感 | 何との関係かを具体的に書く |
| 本でいうと（参考文献の見出し） | 参考 |

## 比喩・内輪の言い方

| 使わない語 | 代わりの書き方 |
|---|---|
| 本丸、逆走 | 指している対象・方向を書く |
| テストが緑 | テストが通る |
| 撃つ、跨ぐ、乗る、潰す（API 呼び出しなど） | 呼ぶ、送る、またがる、消す |
| 写し（dual-write のこと） | 二重書き込み、両方の表への書き込み |
| 叩く（APIやコマンド） | 呼ぶ、実行する |
| 経路、出口、入口、線を跨ぐ | 指している対象・手順・条件を書く |
| 難所 | 起きる事象と条件を書く |
| 直読み | 何をどう読むかを書く（例: `UserSonyPaymentAccount`を読む） |

## 読み手によっては通じない語

| 使わない語 | 代わりの書き方 |
|---|---|
| 塗り足し、トンボ（印刷の用語） | 使うときは、その場で意味を書く |
| 切り替え（社外向けの説明で） | 何から何へ移すかを書く |
| 口座、長寿命（Nuts の文書で） | ユビキタス言語にある語を使う |
| no-op | 何もせずに戻る、列を変えずに終わる、など挙動を書く |
| バックフィル | 既存の行をまとめて更新する |
| その場で作った呼び名（実在するモデル・テーブルを指すもの） | 実際のモデル名・テーブル名をそのまま書く |
| A＝Bのように＝でつないだ言い換え | ふつうの文で書く |
| 〜の計測を確かめる（何を見るか書かずに） | 起きた事実と、見る場所・聞く相手を書く。例: GA の日別の値と、採用サイトの更新の有無を確かめる |
