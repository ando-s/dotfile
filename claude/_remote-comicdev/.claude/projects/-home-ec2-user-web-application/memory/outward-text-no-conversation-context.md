MR・コメント・通知などチーム向けの文面には、**私とユーザーの会話の中でだけ通じる言葉・前提を持ち込まない**。読み手（その文面だけを見る相手）にとって、その場で意味が通るように書く。

NG例: 「2ステップで完結する想定ではありません」← ユーザーとの相談で出た「2ステップ」という枠組みを、それを知らないm-kitano宛のコメントに書いてしまった（「なんのこと？」になる）。

**Why:** 2026-06-24、MR!16595 の返信文に会話文脈由来の「2ステップ」を残し「ここでのやりとりをkitanoさんに投げちゃ気持ち悪い」と指摘された。CLAUDE.md に既出のルール（「読み手が前の説明・定義を覚えている前提で書かない」「チーム内の共有文脈に依存する語を使わない」）を適用できていなかった。

**How to apply:** 外向き文面を書いたら、相手の視点で読み返す。直前の会話・私の提案の枠組み・私が付けた呼び名（「案3b」のような内部ラベルや「2ステップ」のような相談中の区切り）を指す語が残っていないか確認し、その文面単体で意味が通る表現に直す。関連: [[mr-message-use-ubiquitous-language]] [[plain-language-no-jargon]]
