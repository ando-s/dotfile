設計・計画の議論では、まず概念（ドメイン）レベルで責務・用語・対象範囲を整理する。その整理が一区切りついた段階で、実装詳細に進む前にドキュメントへまとめて残す。

**Why:** 概念整理をチャットだけで進めると後から参照できず、詳細設計でぶれる。一度文書化してから詳細に入る方が土台が安定する。

**How to apply:** ドメインレベルで合意ができたら、その時点の整理（責務分担・用語・対象/非対象・確定した前提）を md にまとめる。それを土台に詳細設計へ進む。
