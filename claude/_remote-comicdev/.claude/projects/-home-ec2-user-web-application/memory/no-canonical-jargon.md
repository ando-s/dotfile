「正典」「正典化する」という言葉を使わない。

**Why**: ユーザーから「『正典』という言葉は馴染みが全くないのでやめてください」と明示的な指摘を受けた。比喩・程度強調・チーム内共有文脈のいずれでもなく「その場で使った専門ぶった言い換え語」という別カテゴリだが、既存方針（[[plain-language-no-jargon]]）と同じ「事実をそのまま平易に書く」原則に従う。

**How to apply**:
- 「共通の仕様として設計する」「唯一の参照先とする」「〜に統一する」など、指している事実をそのまま平易な言葉で書く
- ドキュメント本文・見出し・MR説明・コミットメッセージいずれでも同様
- 既存コードベース内に「正典: X.md」という表記が既にある箇所（例: `packs/nuts/.ai/skills/post_review_comment/SKILL.md` 等）は、指摘があるまで無理に一括修正しない。新規に自分が書く文章でこの語を使わないことが優先
