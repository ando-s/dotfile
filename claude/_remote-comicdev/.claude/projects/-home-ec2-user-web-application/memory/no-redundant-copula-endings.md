日本語の文末で「〜からだ。」「〜である。」のように断定の「だ」「である」を足さない。「〜から。」「〜そのもの。」で止める。

- ✗ 動いていたのは、値が決済行に残っていたからだ。
- ○ 動いていたのは、値が決済行に残っていたから。
- ✗ 解約要求に決済側の値を送っているのが、直している問題そのものである。
- ○ 解約要求に決済側の値を送っているのが、直している問題そのもの。

**Why:** 末尾の「だ」「である」は意味を足さず、書き言葉として硬くなるだけ。

**How to apply:** MR説明・コード内コメント・ドキュメントを書いたら `grep -n "だ。\|である。"` で拾って落とす。チャットの短い受け答えにも同じく適用する。関連: [[cognitive-rhythm-writing-norm]]、[[plain-language-no-jargon]]
