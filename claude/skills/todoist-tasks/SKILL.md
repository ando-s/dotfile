# Todoistのタスク

タスクを足す・整理するときは次に従う。

- 入れるのは自分が手を動かすものだけ。JIRAのチケットは、その中で自分がやる次の作業を入れる。会議は入れず、会議の準備と宿題は入れる。AIに任せる作業は入れる。
- 1回座って終わる大きさ（2時間以内）にする。大きいものは期日なしの親タスクにしてサブタスクに分け、分け方が分からないものは「〇〇を分ける」（30分）を1件入れる。
- 題名は動詞で終え、対象（MR番号・チケット番号・相手）を入れる。リンクは説明欄に置き、頭にプロジェクト名を付けない。
- 置き場: 仕事はworkの該当セクション（迷ったらno category task）、繰り返しの仕事はwork / scheduled routine task、私用はprivate、読み物・学ぶものはinput、未整理はInbox。
- Inboxから移すときは、4つの軸（緊急度・重要度・脳みそ労力・不確実性）の高・低のラベルを付け、終えたら「判定済み」を付ける。どちらとも言えない軸には付けない。優先度は付けない。
- 状態のラベルは1つだけ付ける。着手前はなし、途中で止めているものは「作業中リスト」、返事待ちは「連絡待ちリスト」、結果を確かめる段階は「検証中リスト」。
- 期日は「やる日」（続きをやる日・催促する日・確かめる日）にする。締め切りは題名の末尾に「（締め切り11/4）」の形で書く。「いつか」やるものは期日なしで置く。
- privateの「誕生日」セクションは覚え書きなので、判定のラベルを付けない。
