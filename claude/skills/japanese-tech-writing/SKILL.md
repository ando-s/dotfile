# japanese-tech-writing（日本語の文章）

本人の名前で外に出る、まとまった日本語の文章を書くときの規範。
誇張語・比喩・造語を使わない、英数字の前後に空白を入れない、などの共通の規則はグローバル CLAUDE.md に従う。ここでは文章全体の組み立て、本人の書き方、仕上げの点検を持つ。

## 1. 書く前に決めること

- **読み手を1人に決める。** 「Nutsを知らない他チームのエンジニア」「評価者の上長」のように具体的にする。会話の経緯を知らない人を前提にする。
- **文章の種類を決める。** 種類で組み立てが変わる。
  - **調べる文章**（設計ドキュメント・手順書・評価シートのコメント）: 結論を先に置く。見出しと箇条書きで、必要な箇所だけ読めるようにする。グローバル CLAUDE.md の回答の書き方（段落は1〜2文、箇条書き中心）に従う。
  - **読ませる文章**（技術記事・解説・振り返り・登壇の原稿）: 読み手の実感や疑問から入り、最後まで読む理由を途中で切らさない（3節）。本人の書き方（4節）に寄せる。
- **読み終えた後に読み手ができることを1文で書く。** 書けなければ、まだ書き始めない。

## 2. 会話の経緯を成果物に残さない

文章を作るまでの会話は、作るための材料であって、文章の中身ではない。会話の経緯を知らない読み手が読んで自然に読めることを基準にする。

会話の各要素を次の3つに分け、本文に入れるのは1つ目だけにする。

1. **読み手に必要な内容** → 本文に書く。
2. **作り方への指示**（分量・口調・読み手・避けたい表現） → 構成・口調・扱う範囲・前提・例・名前の付け方に反映し、指示そのものは書かない。
3. **会話の残り**（依頼の言い回し、却下した案、使わなかった道具、途中の指摘） → 消す。

### 消すか書き換える文

次のような文を探す。ただし機械的に消さない。読み手が本当に知る必要があるときは残す。

- 「ご依頼のとおり」「ご指示に基づき」「〜という要望を受けて」
- 「当初は〜としていたが」「前の版と違って」「〜に変更した」
- 「〜は使わない」「〜を避けるため」「この制約のため」
- 「この文書は〜を前提とする」「この節は〜のために足した」

### 例と指示の扱い

- **依頼で示された例は、本文に入れない。** 例は、抽象度・読み手・口調・避けたい言い回しを推測する材料にする。例がいつの間にか文章の話題になっていないかを確かめる。
- **制約は断り書きにせず、作りに反映する。**
  - 悪い例:「この手順では Git や CLI を使わない。」
  - 良い例:「プロジェクトのフォルダを Google ドライブで共有する。」
- **「〜に触れない」という指示は、〜を書かないことで守る。** 「〜には触れない」と書かない。
- **「初心者向けに」は、進め方の遅さ・用語の定義・例の多さで実現する。** 「初心者向けに書いた」と書かない。
- この規範の用語（「まだ答えていない問い」「密な段落」など）も本文に出さない。

### 出力

出力は文章そのものにする。「不要な部分を削りました」のような前置きを付けない。何を変えたかの要約は、求められたときだけ文章の後に付ける。説明するより書き直すことを優先する。

## 3. 読ませる文章の流れ

読ませる文章が途中で読まれなくなるのは、情報が多いからではなく、全文が同じ調子で書かれているからである。観察する・迷う・言い切る・確かめ直す、を切り替える。完成した結論を解説する声ではなく、考えながら進む当事者の声で書く。

### 材料の取り方

- **流れの材料は、扱う対象の側からだけ取る。** 出来事・データ・発言・トレードオフ・素朴な見込みが事実で外れること、書き手の判断の状態（思い込み・保留・後悔・譲歩・告白）、読み手が抱く反問。材料が見つからない箇所は、何も足さずに平坦なまま残す。
- **文章自身について語る文で、流れを作らない。** 「〜の列挙はしない」「問いは〜だけである」は、流れを作ったことにならない（5節）。
- **文を削って短くしても、流れはできない。** 冒頭で共有すべき範囲・観点・比較の軸・まだ決まっていないことを削るのは、流れではなく欠落である。

### まだ答えていない問いを持つ

- 文章は常に、まだ答えていない問いを1つ以上持っておく。答えの出ていない問い、裏の取れていない見込み、後で答えると約束したこと、のどれか。すべて答え終えたところで、読み手は読むのをやめられる。
- 立てた問いは、答えずに次の話題へ移らない。答えを前半と後半に分けて返すと、後半を読む理由になる。答えるときは、答えの中身を書く。「先に答えの半分を置く」のように、これからする操作を書かない。

### 文の並び

- 短い文で立てて、長めの文で説明し、短い文で止める。段落の基本はこの順にする。
- 言い切る文だけで押し切らない。言い切る文と迷う文を交互に置く。
  - 言い切る:「〜だった」「〜である」
  - 迷う:「〜とは思う。ただ…」「〜だろうか」
- 後で事実によって外れる見込みを先に書いておくと、読み手の予想を作ってから崩せる。「うまくいっていると思っていた。」→ 次の段落で「ところが、記録を見るとそうではなかった。」 外れることを必ず後の段落で事実で示す。示さないなら、見込みを書かない。
- 話の向きを変えるところでは、「〜だろう。しかし、ここで考えたいのは〜のほうだ。」のように、譲ってから向きを変え、短い文で止める。

### 段落の並び

- 密な段落が2〜3個続いたら、短い段落を1つ置く。短い段落の役目は、決まったことを1行で確かめる、次に判断するものを示す、視点の距離を変える、のどれかにする。
- 具体（記録・数字・発言・コード）に寄る段落と、意味を考えて一歩引く段落を交互に置く。
- 箇条書きは、情報を詰めるためだけでなく、本文の区切りにも使える。箇条書きの後に一歩引いた1文を置く。

### 冒頭

- 最初の数文で、まだ答えていない問いを1つ作る。型は問わない。
  - 読み手の実感を言い直し、仮説を出す（「〜と感じることがある。〜が違うのかもしれない。」）
  - 読み手に問いかけ、すぐ自分の答えを返す
  - 言い切った一般論を置き、本文でそれを確かめる
  - 書き手の思い込みを書き切ってから、事実で崩す
- 予告や要約は、書き手の考えが入った1〜2文なら置いてよい（「言い換えると〜という話である」）。置かないのは、考えの入っていない議題の一覧（「本稿ではA・B・Cを扱う」）だけである。
- 読み手が抱きそうな抵抗（古い・実用的でない・自分には関係ない）は、読み手の言葉で先に書き、短く答えてから本題に入る。

### 節の入り方

- 「本節では〜を扱う」と書かない。次のどれかで入る。
  - 前の節が残した違和感を、当事者の問いとして言い直す
  - 読み手が抱く反問をそのまま書く。すぐ答えず、「そうしたかった、とは思う。」と一度受けてから崩す
  - 書き手の告白から入る（「正直に言うと、〜という算段もあった」）。告白は自分を責めるためではなく、直後の論証の足場として使う
- 理論・概念・引用は、読み手の中に名前のない違和感を作ってから出す。理論は答えではなく、その違和感の名前として出す。
- 節のつなぎは、次の節の頭に置く。前の節の末尾に「次は〜を見る」と書かない。

### 列挙の着地

- 性質や分類を並べたら、各項目を直前の具体的な場面に1つずつ結びつける（「1つ目は、さっき見た〜のことだ」）。
- 結びつけ方を揃えない。正体を指す、身に覚えを書く、固有の事実に対応させる、などを変える。

### 結び

- 抽象的なまとめで終えない。冒頭の場面・読み手自身の経験・序盤の問いなど、読み手がすでに持っている具体に戻してから閉じる。
- 答えの出ていない問いを1つ残して終えてよい。
- 読み手への呼びかけ・依頼・書き手の謙遜や断りは、冒頭と結びにだけ置く。本文の途中の論証に混ぜない。

## 4. 本人の書き方

本人が自分で書いた文章（Obsidian の振り返り・考えのノート）から取った特徴。読ませる文章ではこれに寄せる。技術広報の記事は AI が書いた部分を含むので、文体の手本にしない。

- **だ・である調。一人称は「私」。** 「〜と思う」「〜のかもしれない」で留保し、言い切る文と交互に置く。
- **自問から入る。** 「なぜそうなったのか。」と1行で問い、次の段落で答える。
- **理由は「1つ目。」「2つ目。」と短い行で立て、その後に説明の段落を続ける。**
- **自分の失敗や至らなさを、具体的な事実で書く。** 何に落ちた・何ができなかった、を年月や回数と一緒に書く。自己評価の形容詞（「未熟だった」）で済ませない。
- **短い一言で区切る。** 長い説明の後に、1文だけの感想を置く。
- **言葉の意味を、似た言葉との違いで示す。** 「Aとは、Bとは異なる。Bは〜で、Aは〜である。」のように対で定義する。
- **概念は「」でくくる。** 自分が使い分けている言葉や、他人の言葉を借りるときに使う。
- **参考にした記事は、書くきっかけとして冒頭に置く。** 何を読んで、何をしたくなって書いたかを1〜2文で書く。
- **結論は大きく言い切らない。** 「必要なのは〜ではなく、〜だと思う。」のように、否定と肯定を対にして控えめに締める。

本人の文章を手本として引用するときは、私生活に関わる中身（家族・学生時代・キャリアの悩みなど）を使わない。書き方の型だけを使う。

## 5. 文を残すか消すかの判定

判定の軸は1つだけにする。**その文が新しくしているのは、扱う対象の状況か、文章自身か。**

- **残す**: 対象の出来事・データ・発言、または書き手の判断の状態（思い込み・保留・後悔・譲歩・告白）を新しく伝える文。
- **消す**: この章・この節・ここまでの話が「どう見えるか」「次に何を書くか」だけを伝える文。
  - 「ここまでだと概念の説明に見えるだろう。なので、すぐに例へ戻す。」
  - 「要するに、この章の主題は〜ではなく〜である。」
  - 「誤解しないでほしいのだが、〜を否定したいわけではない。」（退ける誤読を具体的に書いていない弁明）
  - 「テクニックの列挙はしない。」「〜の話ではない。」（否定形でも、話題が文章自身なら消す）
  - 「ここまでで〜は見えた。次の問いは〜である。」（節末の進行予告）
- **短く言い切る形に直しても、消す文は消す。** 文章自身について語る文を短く整えると、決め台詞に見えて残りやすい。これが最も混ざりやすい経路である。短くて調子が良いことは、残す理由にならない。

文章自身について語る文でも、次の4つの形だけは残してよい。

1. **誤読への反論**: 読み手の誤読を「」で具体的に書き出して退ける（「ここまでの話を『〜せよ』と読まれると、それは違う」）。退ける誤読を具体的に引用していることが条件。
2. **問いを立てる文と答える文**: 境界に置く「ここでは〜を考える」（問いを作った後に限る）と、答えの文。「何をしないか」「何の話でないか」の宣言は、これに当たらない。
3. **読み手への依頼・断り**: 冒頭や結びに置く「〜と割り切って読んでほしい」。
4. **例の始まりと終わり**: 架空の例を始める文（「〜としよう」）と閉じる文。節の頭に置く。

### 消し方の手順

1. 文章自身について語る文を見つけたら、まず消して前後を読む。つながるなら、それで終わり。
2. 消すと論理が飛ぶなら、その文が指そうとしていた内容を、対象の状況の側の文に書き換える。
   - 「ここまでだと概念の説明に見える」→「この3つの性質は、どれも冒頭の失敗の中にそろっている」
3. 書き換えた文がまだ文章自身を話題にしているなら（短くしただけ、言い回しを変えただけ）、書き換えは失敗である。上の例外1〜3に当たらない限り、文ごと消して前後をつなぎ直す。

## 6. 書いた後の点検

出す前に、上から順に機械的に確かめる。

1. **文章自身について語る文**: 段落の最初の文と、独立した短い文をすべて拾い、5節の軸で判定する。推敲で新しく書いた文・短く割り直した文は、書いた直後にもこの判定にかける。
2. **会話の残りと規範の用語**: 2節で消すと決めた語・文が残っていないか。依頼の例文や、この規範の用語がそのまま入っていないか。すべての節の末尾に「次は〜」の予告が無いか。
3. **問いの台帳**: 立てた問い・思い込み・約束を並べ、それぞれに答えた行を指す。指せないものは、答えを書き足すか、問いごと消す（読ませる文章）。
4. **文の並び**: 言い切る長い文が3つ以上続く箇所に、短い文か迷う文を入れる。
5. **呼びかけと謙遜の位置**: 冒頭と結び以外に入っていないか。入っていれば境界へ移すか消す。
6. **見出しと注記**: 書き手のためではなく、読み手のために書いてあるか。
7. **用語と口調**: 同じものを別の語で呼んでいないか。です・ます／だ・であるが混ざっていないか。何度か直した継ぎ目が残っていないか。
8. **確認の境界**: 確認していないことを断定していないか。未確認は「未確認」と書いたか。

## 7. 症状と直し方

| 症状 | 直し方 |
|---|---|
| 全段落が同じ調子で疲れる | 6節の4で、長い言い切りの連続に短い文か迷う文を入れる |
| 正しいのに読み進めたくならない | 答えていない問いが無い。冒頭で問いを1つ作り、6節の3で以降も常に1つ持っているか確かめる |
| 理論の節で読み手が離れる | 理論が違和感より先にある。反問か告白を理論の前に置き、列挙は場面に1つずつ結びつける |
| 緩い文があるのに、だらけて見える | 緩い文が文章の進行の実況になっている。5節で判定し、判断の保留・思い込み・感情の小さな差など、状況の側の文に書き換える |
| 結びが説教くさい | 抽象的なまとめで閉じている。読み手がすでに持っている具体に戻す1文を結びの先頭に置き、答えの出ていない問いを1つ残す |
| 冒頭が事務的 | 考えの入っていない議題の一覧になっている。削るのではなく、予告に書き手の考えを入れるか、予告の前に読み手の実感や抵抗への答えを置く |
| 何が言いたいのか分からない | 1節の「読み終えた後にできること」が書けていない。そこから決め直す |
| 継ぎはぎに見える | 何度か直した跡が残っている。用語と口調を揃え、言い直しを1つに絞る |
| 本人の文章に見えない | です・ます調や「〜しましょう」になっている。4節に寄せる |
