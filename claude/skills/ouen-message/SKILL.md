# ouen-message（時間帯別応援メッセージ送信）

業務時間中の定期実行を想定し、現在時刻に合ったトーンの応援メッセージを 1 通送る。

## 手順

1. 現在時刻を確認する

   ```bash
   date "+%H時%M分 %a"
   ```

2. 下の時間帯テーブルからトーン指針を選ぶ
3. メッセージを生成する（後述の文面ルールに従う）
4. 送信する

   ```bash
   ~/.slack/send-ouen.sh "<@U04HDG7FHM1> <メッセージ本文>"
   ```

## 時間帯テーブル

| 時間帯 | トーン指針 |
|--------|-----------|
| 〜11:00 | 午前の集中を後押し。タスクを小さく刻む提案 |
| 11:00〜11:30 | 昼前ラストスパート。キリのいいところまで + 水分補給 |
| 11:30〜12:00 | 昼休憩の促し。手を止めてごはんへ |
| 12:00〜13:00 | 昼休みリフレッシュ。仕事を忘れて休む |
| 13:00〜14:00 | 午後イチのウォームアップ。軽い作業から流れを作る |
| 14:00〜15:00 | 眠気対策。歩く・冷たい水・無理にギアを上げない |
| 15:00〜16:00 | 小休止の提案。甘いもの・コーヒー → もうひと押し |
| 16:00〜17:00 | 仕上げモード。新しい大仕事は始めず手元を区切る |
| 17:00〜18:00 | 終業前のまとめ。今日必ず終える一つに絞る・明日の準備 |
| 18:00〜 | 定時後のねぎらい。オフへの切り替え・休息 |

## 文面ルール

- 構成は「ねぎらい → 軽い行動提案 → 前向きな締め」の 3 部
- 4 文程度、です・ます調、絵文字は 1〜2 個（冒頭の時間帯絵文字 + 末尾）
- 追い込まない。「明日に回してOK」「マイペースで」のように力を抜かせる方向で書く
- 同日の直前メッセージと言い回し・絵文字が重複しないよう変化をつける
